# Roadmap

This roadmap outlines the current direction and priorities for QuokkaDB.

It reflects where we intend to focus our efforts, but it is not a fixed commitment. Priorities may evolve based on community feedback, real-world usage, technical discoveries, and the needs of the project.

Our long-term goal remains the same: to make QuokkaDB a reliable, performant, and easy-to-use embedded document database.

## 1. Reliability, performance and stabilization

- Expand crash testing, fuzzing and fault injection.
- Establish reproducible performance benchmarks.
- Identify and optimize bottlenecks in reads, writes, indexing and compaction.

## 2. Transactions

- Atomic multi-document operations.
- Multi-collection transactions.
- Transaction isolation and conflict detection.

## 3. TypeScript / Node.js support

- Native bindings.
- Idiomatic document API.

## 4. Advanced indexing

- Unique indexes.
- Partial and sparse indexes.
- Additional indexing capabilities driven by demand.

## 5. Python support and ecosystem

- Python bindings.
- Integration with existing tools and frameworks.
