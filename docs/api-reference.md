# API Reference

This chapter will provide a curated map of the public Rust API. It will explain which entry points fit each task; generated rustdoc remains the exhaustive reference for methods and types.

## Planned topics

- `QuokkaDB`: opening a database, options, collections, and metrics.
- `Collection`: direct BSON document access and operation builders.
- `TypedCollection<T>`: model-oriented reads, writes, updates, and indexes.
- `QuokkaDocument` and `QuokkaType`: deriving model support.
- Typed fields, filters, selections, sorts, indexes, and updates.
- `Options`, `StorageQuantity`, and `WalDurability`.
- Results, errors, IDs, index metadata, and collection metadata.
